# Vendra Affiliate

Tenant-aware affiliate for Vendra applications.

## Requirements

- PHP 8.2+
- Laravel 12
- Filament 5
- Livewire 4
- Pest 4
- Tailwind CSS 4

## Installation

```bash
composer require misaf/vendra-affiliate
```

## Testing

```bash
composer test
```
